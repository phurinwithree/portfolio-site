## เกี่ยวกับโปรเจค

โปรเจคนี้สร้างขึ้นเพื่อใช้เป็นพื้นที่แสดงผลงานและเขียนบทความของตัวเอง พร้อมกับฝึกทักษะ Full-Stack Development ครบทุกส่วน ตั้งแต่ออกแบบฐานข้อมูล สร้าง API ทำหน้าเว็บ ไปจนถึงนำขึ้นออนไลน์จริง

## ฟีเจอร์

**หน้าบ้าน (ผู้เข้าชมเห็น)**

- หน้าแรก แนะนำตัว
- ผลงาน และหน้ารายละเอียด
- บทความ และหน้าอ่าน
- โปรเจคที่กำลังทำ พร้อมสถานะและลิงก์ไป GitHub
- หน้าติดต่อ

**หลังบ้าน (เจ้าของล็อกอินเข้าไปจัดการ)**

- ระบบล็อกอิน
- เพิ่ม แก้ไข ลบ ผลงาน บทความ และโปรเจค
- อัปโหลดรูปภาพ
- ตั้งสถานะฉบับร่าง หรือเผยแพร่

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| ภาษาหลัก | JavaScript |
| Backend | Node.js, Express |
| ฐานข้อมูล | SQLite |
| Frontend | HTML, CSS, React |
| เครื่องมือ | VS Code, Git, GitHub, Postman |

## ภาพรวมการทำงาน

ผู้เข้าชมเปิดหน้าเว็บ (React) หน้าเว็บจะเรียกข้อมูลจาก API ที่สร้างด้วย Express แล้ว Express ไปดึงข้อมูลจากฐานข้อมูล SQLite ส่งกลับมาแสดงผล ส่วนเจ้าของเว็บล็อกอินเข้าหน้า Admin เพื่อส่งข้อมูลใหม่ผ่าน API ไปเก็บในฐานข้อมูลเส้นทางเดียวกัน
